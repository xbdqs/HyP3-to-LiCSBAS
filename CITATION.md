# Citation

GitHub reads `CITATION.cff` and exposes a **Cite this repository** control on the repository page.

Current software citation metadata:

> Du, Q. HyP3-to-LiCSBAS (version 1.0.1) [Computer software]. https://github.com/xbdqs/HyP3-to-LiCSBAS

After publication of the associated SoftwareX article, the journal citation can be added as the preferred citation while retaining the software-version metadata.
